Goal of the tests in KDL :
==========================

All numerical calculations that are non-trivial should be tested by
a testprogram.  This is important because these kinds of errors are difficult to trace 
when they occur in an application.  

The tests are run automatically when using "make check".

Test programs should give a short message on std::cerr  and a long log of their activities on std::cout.
Test programs should exit with a non-zero status number if an error occurred.

(make check > log   , if you want the log into a file.)




Description of the tests in KDL:
================================

The tests live in tests/ and are registered with CTest (configure with
-DENABLE_TESTS=ON). Each <name>test.cpp is one CppUnit program; run all of them
with "make check", or "ctest" from <build>/tests.

framestest.cpp :
   - consistency of Vector, Rotation, Frame, Twist, Wrench, the 2D types and
     JntArray and all of their mathematical operations,
     e.g. R*R.Inverse() == Rotation::Identity(), or (R*(R*v)) == (R*R)*v.
   - quaternion, Euler/RPY and GetRotAngle round trips, Norm() of small vectors,
     the tolerance rules of Equal(), exact operator== and std::hash.

framesconsistencytest.cpp :
   - checks every function of frames, framevel, frameacc and utilities/utility
     against a reference that does not go through KDL: the double types against
     Eigen, the rotation parameterizations against Eigen::AngleAxisd and
     Eigen::Quaterniond, and the Vel and Acc types (VectorVel, RotationVel,
     FrameVel, TwistVel, doubleVel, and their Acc counterparts) by finite
     differences of the plain double operation.

inertiatest.cpp :
   - RotationalInertia, RigidBodyInertia and ArticulatedBodyInertia: construction,
     arithmetic, and the transformation by rotations, frames and RefPoint().

jacobiantest.cpp :
   - the Jacobian class: construction, changeRefPoint, changeRefFrame, changeBase
     and Equal.

jacobiandottest.cpp :
   - ChainJntToJacDotSolver against numerical differentiation of the Jacobian, for
     the hybrid, body-fixed and inertial representations on several chains, and
     against the symbolic Jdot of a two-link arm.

kinfamtest.cpp :
   - the kinematic family classes Joint, Segment, Chain and Tree.

solvertest.cpp :
   - the chain solvers: forward position and velocity kinematics against the
     Jacobian, inverse velocity and position kinematics against the forward
     solvers, the vector versions of JntToCart, the Vereshchagin hybrid dynamics
     solver, the external wrench estimator, the forward dynamics solver, the LDL
     decomposition, and updating the solvers after the chain changed. Several of
     these tests use random configurations.

treeinvdyntest.cpp :
   - TreeIdSolver_RNE against ChainIdSolver_RNE on a tree built from two chains,
     against an analytic Euler-Lagrange model of a Y-shaped tree, and its size
     checks and update after the tree changed.

pathtest.cpp :
   - Path_Circle: Clone() and writing and reading back a path give the same path.

velocityprofiletest.cpp :
   - the trapezoidal, half-trapezoidal and Dirac velocity profiles.

indexcheck.cpp :
   - not a CppUnit program: checks that an out-of-range index into a Vector aborts
     through assert(). It is not registered on Windows, where its test needs a
     POSIX shell.
